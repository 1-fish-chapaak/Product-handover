# Impeccable — Design Context for Auditify (irame)

> Canonical source: `DESIGN.md` (full Editorial GRC system) + `PRODUCT.md` (audience and principles).
> This file is the distilled, always-loaded version for design skills. When in conflict, `DESIGN.md` wins on tokens and component rules.

## Design Context

### Users

Internal auditors at irame using Auditify on real audit work — asking data questions of evidence, building re-runnable workflows, classifying and resolving exceptions. They are domain experts, not chat-app novices; comfort with Claude / Notion AI / ChatGPT is assumed. They work long sessions on large monitors, often mid-engagement, often with deadlines, switching between "what is this data telling me?" and "operationalize this into something we can run every quarter."

**Job to be done:** Get from a question or an intent to a trustworthy, citable, re-runnable artifact — without learning two products and without losing the thread.

### Brand Personality

**Editorial · confident · calm.**

The voice of a senior auditor who has done this a thousand times: precise, unhurried, willing to show its work. Authority comes from substance (real data, real citations, exposed reasoning) — not from chrome. The interface earns trust by being legible and skeptical, not by performing delight.

### Aesthetic Direction

**"The Senior Auditor's Notebook."** Set, not styled. Warm paper canvas (`#FCFAFD`) under a clean elevated sheet (`#FFFFFF`), softened by a subtle radial mesh. Ink-toned typography. Source Serif 4 for moments of authority. Inter on the working surface. JetBrains Mono on every number, ID, and evidence excerpt. Royal Audit Purple (`#6A12CD`) used as the auditor's pen — present on ≤10% of any screen.

**Anti-references** (this product is explicitly NOT these):
- Generic AI chat apps (centered bubble streams, sparkle iconography, glow chrome)
- Heatmap compliance dashboards (RAG ramps, risk-rating thermometers)
- Consumer-cute (mascots, illustrative blobs, pastel gradients, rounded-everything)
- SaaS template (hero-metric tiles, identical card grids, glassmorphism, gradient text)
- Loud AI chrome (glowing borders, shimmer-while-streaming, AI provenance pills)

**Theme:** Light surface canvas with **one** dark sidebar (`brand-900`, `#26064A`). No dark modals, no dark cards. If a surface feels like it wants to be dark, give it more whitespace instead.

### Design Principles

1. **Workspace is the deliverable.** Chat is the entry point; artifacts (queries, workflows, reports, exceptions) are what auditors take away. Visual weight, motion, and color all bias toward the artifact, never the chrome around it.

2. **Editorial confidence, not SaaS template.** Source Serif for authority moments; Inter for the working surface; JetBrains Mono for evidence. Type carries the brand. When in doubt, set it in serif and give it room. Never reach for hero-metric tiles, gradient text, or glassmorphism.

3. **GRC semantics, not a heatmap.** `risk` / `high` / `mitigated` / `compliant` / `evidence` are first-class nouns. They appear one at a time, paired with an icon or label — never side-by-side as a thermometric ramp. Severity is editorial, not thermometric.

4. **Breathing space over decoration.** Color is rare and load-bearing. The default surface is paper + ink; semantic color appears where it carries meaning, not as a background tint per tile. **A row of four cards in four different tones is a smell — collapse it to one neutral surface with semantic color reserved for the numbers or icons that need it.**

5. **Show the reasoning.** Citations are first-class, clickable, and lead to evidence. The auditor must be able to audit the auditor. Sources, plans, and assumptions render inline — never hidden behind chrome.

6. **Tabular numerics, always.** Every number — KPI, table cell, timestamp, percentage, currency, ID, version — wears `font-variant-numeric: tabular-nums`. Mixed-width numerals are a bug.

### Polish Direction (current)

The product has accumulated color noise on several surfaces (Manage Exceptions → Exceptions KPI strip is the canonical example: four cards, four tones, three different background tints in a row — exactly the RAG ramp DESIGN.md prohibits). Active polish work prioritizes:

- **Reduce color count per screen.** Default tiles to the neutral surface; reserve semantic color for the numeric value or a small icon dot, not the entire card background. The auditor's pen rule (≤10% surface) extends to semantic colors when they're used decoratively rather than as a state signal.
- **Add breathing space.** Density should be comfortable, not cramped. The Editorial GRC system already specifies generous vertical rhythm; honor it. Stat tiles need air between rows; tables need adequate row height; section gaps need to be felt.
- **Bias toward readability.** Type hierarchy carries the page. A 28px tabular number with a 12px muted label is more readable than a colored tile competing for the same attention.

### Accessibility & Inclusion

- **Target:** WCAG 2.1 AA baseline across every surface; AAA on text contrast and primary task paths.
- **Keyboard:** Full navigation; visible focus rings on every interactive element. The global 4px `brand-600 @ 24%` ring is the single accessibility signature — do not remove or restyle per-component.
- **Motion:** Exponential ease-out at 150–200ms. No bounce, no elastic. `prefers-reduced-motion` honored — reduces all animations to ~0.01ms globally.
- **Color blindness:** Semantic state never relies on color alone. Always pair with icon, label, or position. The GRC palette is already tuned away from pure red/amber/green.
- **Density:** Comfortable line lengths (65–75ch for body, 66ch cap on AI responses). Long sessions on large monitors are the dominant context.

### Operational Anti-Patterns (recent feedback)

Captured here so future design work doesn't reintroduce them:

- **No editorial citation markers on report bullets** (`F·01`, `O·01` style). Plain purple dot bullets only.
- **No inline numeric/ID regex highlighting** in report body (mono + semibold on `140`, `95,631,064.00`, `VENDOR_002`). Keep numbers in the running prose register.
- **No AI provenance pills** (`Sparkles · AI-generated · {date}`). The product is AI-native; chrome that announces it reads as theater.
- **No section header accent rules with counts** (`FINDINGS ──── 05`). Plain uppercase section header only.
- **No subtle row-hover bg tints on report bullets.** They read as interactive when they're not.
